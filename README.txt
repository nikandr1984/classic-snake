Small Snake - это мой первый учебный проект. Полноценная мини-игра, основанная
на механиках классической Змейки, с некоторыми модификациями. Есть геймплей,
игровой цикл, UI и HUD элементы, звуки и даже локальная таблица лидеров.
Разработано на Unity 6.

Правила: управляй змейкой, ешь, расти, не врезайся.

Условие победы: набрать рекордное количество очков. 

Особенности: Каждые 10 съеденных яблок повышается уровень игры, тело змейки обнуляется,
а скорость возрастает. Динамичности геймплею добавляет наличие несколько типов яблок,
дающих различные эффекты.
